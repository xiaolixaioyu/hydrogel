# 基于卷积神经网络的水凝胶温度智能识别系统

## 背景
温敏变色水凝胶是一种能够在不同温度下发生可逆颜色变化的智能高分子材料。当水凝胶贴附于婴儿皮肤表面时，其颜色会随体温变化而发生规律性改变。本系统旨在利用卷积神经网络（CNN）建立水凝胶图像颜色特征与实际温度之间的回归映射关系，实现基于智能手机拍照的非接触式体温智能检测。

系统需解决的核心技术挑战包括：
- 环境光照多样性导致的颜色偏移问题
- 不同肤色背景对水凝胶颜色感知的干扰问题
- 不同拍摄设备（手机型号、摄像头参数）带来的色彩差异
- 小样本条件下的模型泛化能力问题

## 技术方案

### 系统架构
采用端到端的深度学习方案，整体分为三个阶段：

1. **数据构建阶段**：在受控与自然混合条件下采集水凝胶在不同已知温度下的图像数据集，通过系统化的数据增强策略扩充样本多样性

2. **模型训练阶段**：设计轻量级卷积神经网络（Lightweight CNN），以水凝胶图像为输入、温度值为回归目标进行端到端训练

3. **模型部署阶段**：将训练好的模型转换为TensorFlow Lite格式，部署至微信小程序端

### 核心算法

#### CNN回归网络（CNN Regression）
- **网络输入**：RGB三通道图像（128 x 128 x 3）
- **网络输出**：标量温度值 T（单位：摄氏度）
- **损失函数**：均方误差（Mean Squared Error, MSE）
- **特征提取**：多层卷积核自动提取图像中的颜色分布特征、纹理特征和空间特征

#### 网络架构
```
输入层 (128x128x3)
    ↓
卷积块1: Conv2D(32) + BatchNorm + Conv2D(32) + MaxPool → 64x64x32
卷积块2: Conv2D(64) + BatchNorm + Conv2D(64) + MaxPool → 32x32x64
卷积块3: Conv2D(128) + BatchNorm + Conv2D(128) + MaxPool → 16x16x128
卷积块4: Conv2D(256) + BatchNorm + GlobalAvgPool → 256
    ↓
全连接层: Dense(256) + Dropout(0.3) → Dense(128) + Dropout(0.2) → Dense(1, linear)
    ↓
输出层 (温度值)
```

#### 关键技术
- **批归一化（Batch Normalization）**：加速收敛、提升稳定性
- **全局平均池化（Global Average Pooling）**：减少参数量、增强空间不变性
- **Dropout正则化**：防止过拟合
- **数据增强**：亮度变化、旋转、缩放、翻转、平移

### 训练策略
- **优化器**：Adam（初始学习率 0.001）
- **Batch Size**：16
- **最大训练轮数**：100（配合早停机制）
- **早停耐心值**：15轮
- **学习率衰减**：factor=0.5，patience=5
- **评估指标**：MAE < 0.5°C，RMSE < 0.7°C，R² > 0.95

## 部署方案

### TensorFlow Lite转换
- 加载 Keras 模型（.h5格式）
- 使用 TFLiteConverter 转换
- 应用 float16 量化（减小约50%体积）
- 输出：hydrogel_temp.tflite（< 5MB）

### 微信小程序功能
- 用户拍照/选择照片
- Canvas 图像预处理（128x128，归一化）
- TFLite 模型推理
- 温度预警显示

### 温度预警规则
| 温度范围 | 状态 | 提示信息 |
|---------|------|---------|
| < 37.5°C | 正常（绿色） | 体温正常，请继续观察 |
| 37.5 - 38.5°C | 轻度发热（黄色） | 轻度发热，建议物理降温并密切观察 |
| > 38.5°C | 高烧预警（红色） | 高烧预警，请立即就医！触发手机震动 |

## 数据集规范

### 采集要求
- **温度范围**：35.0°C 至 41.0°C，间隔0.5°C，共13个采样点
- **每温度照片数**：40-50张
- **总数据量**：520-650张

### 条件覆盖
- **肤色背景**：4种（Fitzpatrick I-VI型）
- **光照条件**：4种（自然日光、室内白光、室内暖光、混合光源）
- **拍摄角度**：正面垂直、左倾15度、右倾15度
- **拍摄距离**：10cm（近）、20cm（中）、30cm（远）

### 数据集划分
- 训练集：80%
- 验证集：20%

### 数据清洗标准
- 删除模糊、过曝/欠曝、水凝胶不完整、温度偏差超过0.3°C的照片
- 同一条件下的重复照片只保留一张
